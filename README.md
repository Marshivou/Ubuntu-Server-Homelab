# Ubuntu Server Homelab

## Overview
Built and configured an Ubuntu Server virtual machine for networking, Linux administration, and web hosting practice.

## Technologies Used
- Ubuntu Server 24.04 LTS
- Nginx
- OpenSSH
- UFW Firewall
- VirtualBox

## Features
- Remote SSH administration
- Nginx web server hosting
- Firewall configuration with UFW
- Linux networking configuration
- System monitoring and troubleshooting

## Skills Demonstrated
- Linux administration
- Networking fundamentals
- Server deployment
- Service management
- Basic cybersecurity practices
